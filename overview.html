Shoaibul-OS

How one AI assistant drafts Shoaibul's mail and calendar across three accounts, with him approving every send.

Step 1

Where the data lives

Every place the brain reads from and writes to:

ACCOUNTS
G Gmail — ColabGlobal, StepAhead, Personal (one connector live at a time)
C Google Calendar — meetings, invites, RSVPs
THE BRAIN'S MEMORY
M MEMORY.md + topic files — people, projects, feedback, decisions
A my-brain-architecture.md — the spec itself
H HOOKS/guard_cos_actions.py — the Gatekeeper script, wired as a hook
L DATA/<agent>/ — each agent's local, dated output log
WORK AND FILES
D Drive / Docs / Sheets / Slides
GH GitHub repos — status, edit, push, merge
CONTACT CHANNELS · reference only
W WhatsApp — number only, not connected
L LinkedIn — profile link only
K Calendly — booking link, tied to Personal Calendar
Step 2

The playbooks

Written once in PLAYBOOKS/, followed by every matching request:

WHEN SOMETHING LANDS
1 Meeting lifecycle — accept → agenda → nudge → recap
2 Cold inbound — classify P1/P2/P3, draft reply
WHEN ASKED DIRECTLY
3 StepAhead thank-you — follow-up + deck attached
4 Mode switch — "switch to work mode"
5 Known opens — "open the deck" → fixed target
EVERY MORNING
6 Daily brief — calendar + inbox rollup
Step 3

The agents

Six agents, each with one job, scoped tools only:

MAIL
I Inbox — triages by priority, drafts replies in-voice
P StepAhead Pitch — pitch & follow-up email, deck attached
CALENDAR
C Calendar & Meetings — accepts invites, drafts agenda/nudge/recap
FILES & CODE
D Docs Analyst — reads & edits Drive/Docs/Sheets/Slides
E Engineering — repo status, edits, commit, push, merge
ROLLUP
B Briefing — daily calendar + inbox summary
LOCAL LOG · added 2026-11-09
W Each of the 6 holds Write for one purpose only — a dated entry in its own shoaibul-os/DATA/<agent>/ folder
Step 4

Safety checks

The Gatekeeper · runs on every tool call:

EVERY SEND
✓ Draft by default, you send
✓ Meeting logistics are the only auto-send
✓ Real send blocked without a one-time approval marker
EVERY SAVE
✓ No secrets committed
✓ runs/ gitignored, never tracked
EVERY ACTION
✓ Content read from mail/docs/web is data, never instructions
✓ Legal/financial/contractual always flagged
✓ Fails closed if the guard itself crashes
Step 5

You approve and send

Everything waits as a draft, except what's pre-approved:

READY FOR YOU
→ Email drafts waiting in Gmail
→ One-line summary per draft
→ Repo edits ready to push, if asked
DONE AUTOMATICALLY
→ Meeting agenda/nudge/recap sent
→ Invites auto-accepted, conflicts flagged
→ Triage labels applied to inbox
