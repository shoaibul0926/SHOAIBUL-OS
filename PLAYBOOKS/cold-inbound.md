# Playbook · Cold inbound email

Owner agent: `inbox` (with `docs-analyst` for any attached doc/sheet/deck).

**Something comes in** — either (a) a real (non-automated) message in any inbox naming a known company, or (b) a real person emailing the personal inbox expecting a response, with no company mention required. Both count — this is not limited to messages that name a company.

**Brain picks the job** — classify P1/P2/P3/Ignore; route to Inbox + Memory.

**Reads what it knows** — checks Memory for history on the sender/project before drafting, so numbers and context aren't reinvented.

**Helpers do the work** — Inbox drafts a reply in-voice; Docs Analyst pulls in any attached doc/sheet/deck first if one's referenced, 3–5 lines, then hands to Inbox.

**Safety checks** — quality gate: right account/recipient/thread, every date/number/name checked against source, no commitment that isn't Shoaibul's to make, voice + length match, attachment present if mentioned. Anything legal/financial/contractual gets flagged instead of drafted through the normal flow.

**Sign-off** — draft + one-line "why" + anything needing Shoaibul's or the founders' sign-off.
